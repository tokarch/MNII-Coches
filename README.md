# MNII-Coches

Práctica de Métodos Numéricos II sobre interpolación y análisis espectral del consumo de combustible de vehículos.

## Contenido

- Interpolación de Lagrange
- Interpolación de Newton
- Spline cúbico natural
- FFT
- Análisis de error
- Visualización gráfica
